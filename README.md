## 🌐 What is MarineGuardian?

> **MarineGuardian** is an integrated, full-stack, autonomous maritime multi-hazard surveillance, dynamic vessel rerouting, and multilingual coastal safety intelligence platform. Built for the **Indian Exclusive Economic Zone (EEZ)** and critical **Asian Sea Lines of Communication (SLOC)**, it unites **satellite microwave radar (SAR)**, **deep learning computer vision**, **live AIS telematics**, **ocean wave physics**, and **localized NLP advisories** into a single cohesive decision-support ecosystem.

```python
# MarineGuardian Autonomous End-to-End Operational Pipeline
raw_satellite_telemetry
  → 🛰️ SAR Oil Spill Segmentation   # ResNet-34 U-Net (65.09% mIoU | 78.68% Dice)
  → 🪸 Underwater Debris Detection  # YOLOv8n (64.7% mAP@50 @ 625 FPS / 1.6ms)
  → 🚢 Hybrid AIS Fleet Telemetry   # Live AISStream.io WebSockets + 40+ EEZ Baseline
  → 🌊 Hydrodynamic Route Analysis  # Seaward Normal Vector Offset (Hs >= 2.8m ceiling)
  → 🗣️ Multilingual NLP Advisories  # Hindi, Marathi, Gujarati (+ In-Situ Optical Profiles)
  → 🚨 Cloud Distress Relay         # Resend HTTPS API Multi-Stakeholder Dispatch ✅
```

### 🗣️ Module 1: Coastal Fishermen Safety & Water Quality Command Center (`/command`)

<p align="center">
  <img src="https://img.shields.io/badge/Open--Meteo-Marine%20Physics-0284C7?style=for-the-badge&logo=fastapi&logoColor=white" />

  <img src="https://img.shields.io/badge/Resend-Cloud%20SOS%20Dispatch-EF4444?style=for-the-badge" />

* **In-Situ Sea State Physics:** Real-time extraction of Significant Wave Height ($H_s$), Secondary Swell ($H_{\text{sw}}$), Wave Period ($T_p$), Surface Wind ($U_{10}$), 16-point Compass Bearing, Ocean Currents, and Solar Ephemeris.
* **Dual Nautical Classification:** Evaluates sea conditions using the **Beaufort Wind Scale (Force 0–12)** and **Douglas Sea State Rating (Degree 0–9)** paired with verified real-world optical wave profile photographs.
* **Segmented Fleet Operating Clearance:** Tailored operational directives for **Small Traditional Crafts ($< 12\text{m}$)** vs. **Mechanized Trawlers ($12\text{--}24\text{m}$)** based on nearshore breaker hazards.
* **Multilingual Vernacular Generation:** Instant localized translation into **Hindi (`हिन्दी`)**, **Marathi (`मराठी`)**, and **Gujarati (`ગુજરાતી`)** (extendable to Tamil, Malayalam, Telugu, and Bengali).
* **Automated Level 2/3 Triggers & Emergency SOS Uplink:** Automatically fires structured advisory emails when wave height reaches Alert Level 2/3, with a dedicated **"🚨 Force Emergency SOS Email Dispatch"** button in Tab 4 connected to the Indian Coast Guard SAR (1554) hotline.

### 🛰️ Module 2: Satellite SAR Oil Spill & Environmental GIS Intelligence (`/gis`)

<p align="center">
  <img src="https://img.shields.io/badge/PyTorch-ResNet--34%20U--Net-EE4C2C?style=for-the-badge&logo=pytorch&logoColor=white" />

* **Satellite SAR Semantic Segmentation:** Uses a pre-trained **ResNet-34 U-Net** on European Space Agency (ESA) Sentinel-1 C-Band radar scenes ($512\times 512$). It discriminates true hydrocarbon slicks from natural organic look-alikes across 5 distinct pixel classes: Clean Sea, Oil Slick, Look-Alike, Ship, and Land.
* **Global Slick Tracking (SkyTruth Cerulean):** Live ingestion of verified satellite radar slick polygons, estimating surface area ($\text{km}^2$), detection source, and matched polluter vessel MMSI.
* **Subsea ROV Marine Debris Vision:** Ultra-low latency **Ultralytics YOLOv8n** model scanning underwater surveillance footage from the **TrashCan 1.0 dataset** (7,212 frames across 22 classes) at **$625\text{ FPS}$ ($1.6\text{ ms}$)** to spot floating plastics, ropes, and net-destroying ghost fishing nets.
* **224-Band Hyperspectral Profile (HSI):** Laboratory simulation profiling spectral absorption signatures of heavy crude vs. light sheen across vulnerable mangrove mudflats and coral reef ecosystems.

### 🚢 Module 3: Commercial Fleet Telematics, AI Rerouting & Multi-Stakeholder Dispatch (`/fleet`)

<p align="center">
  <img src="https://img.shields.io/badge/AISStream-WebSocket%20Telematics-0284C7?style=for-the-badge&logo=websocket&logoColor=white" />

* **Hybrid AIS Telematics Engine:** Ingests live NMEA-0183 WebSocket streams (`[LIVE AISSTREAM]`) blended seamlessly with a certified **40+ vessel All-India EEZ baseline registry** (`[EEZ BASELINE]`), ensuring uninterrupted situational awareness across the Arabian Sea, Bay of Bengal, and Malacca Strait.
* **Hydrodynamic Wave-Ceiling Rerouting:** When significant wave height exceeds operator safety limits ($H_s \ge 2.8\text{ m}$) or intersects an oil slick, the system synthesizes an optimal deepwater bypass corridor.
* **Mathematical Seaward Guard Rule:** Calculates forward direction vectors ($\vec{D}_i$) and orthogonal normal vectors ($\hat{N}_i$). On India's West Coast ($\lambda < 77^\circ\text{E}$), it automatically inverts eastward vectors to force ships away from shallow coastal shoals and out into deep, navigable oceanic waters.
* **Haversine Refuge Allocation:** Automatically calculates great-circle distance and ETA to the nearest sheltered emergency harbor among India's 12 major ports (e.g. Mormugao Base, Kandla, Mumbai).
* **Multi-Stakeholder Dispatch:** Synchronizes structured HTML advisories across Vessel Bridge, Origin Port Authority, Destination Port, and Refuge Harbor, sandboxed to the prototype terminal (`zameershaikh17112006@gmail.com`).

## 📐 Mathematical Rerouting Formulation

```latex
1. Hazard Detection Condition:
   max { Hs(p) : p in P } >= 2.8m  OR  Intersects(P, Polygon_slick) = True

2. Forward Waypoint Vector:
   D_i = (phi_i+1 - phi_i-1, lambda_i+1 - lambda_i-1)

3. Orthogonal Unit Normal Vector:
   N_hat_i = (-D_i,lambda / ||D_i||,  D_i,phi / ||D_i||)

4. Seaward Guard Rule (West Coast Inversion):
   If lambda < 77.0°E and n_lambda > 0:
       N_hat_i <-- -N_hat_i   (Forces detour westward into deep water!)

5. Candidate Detour Waypoint:
   p_i(detour) = p_i + (delta_margin / 60.0 * alpha) * N_hat_i
```

* **Average Detour Distance Overhead:** $+15.0\text{ to } +22.5\text{ nm}$ (e.g. COSCO DEVELOPMENT: $+18.2\text{ nm}$).
* **Average ETA Delay:** $+1.6\text{ to } +2.3\text{ hours}$.
* **Fuel Variance Penalty:** Evaluated via Admiralty coefficient ($\Delta F \approx 0.26 \times \Delta d \approx 5.22\%$).

## 🚀 Quickstart & Local Installation

### 1. Clone the Repository
```bash
git clone https://github.com/Zameer17/MarineGuardian.git
cd MarineGuardian
```

### 2. Backend Setup (FastAPI & PyTorch)
```bash
# Create and activate virtual environment
python -m venv venv
venv\Scripts\activate   # On Windows (or source venv/bin/activate on Linux/Mac)

# Install optimized dependencies
pip install -r requirements.txt

# Run the FastAPI server
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```
*API Documentation will be available at:* `http://127.0.0.1:8000/docs`

### 3. Frontend Setup (React 19 & Vite)
```bash
cd frontend-react
npm install
npm run dev
```
*Web Dashboard will be available at:* `http://localhost:5173`
